# NEWEB 성수 · 남성 전문 헤어살롱 원페이지

미니멀 · 블랙 앤 화이트 · 에디토리얼 톤의 정적 원페이지 웹사이트입니다.
정적 HTML/CSS/JS로만 구성되어 있어 별도 빌드 없이 바로 배포할 수 있습니다.

## 실행

`index.html` 파일을 브라우저에서 열면 됩니다. 로컬 서버로 확인하려면:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 구성

- **Hero** — NEWEB 성수 / "개인의 무드에 감각적인 디테일을 더해드립니다."
- **Portfolio** — 포트폴리오 갤러리
- **Director** — 강단 원장 소개
- **Contact** — 카카오톡 상담 · 네이버 예약 버튼

## 내 콘텐츠로 교체하기

폰트: Pretendard(한글) + Cormorant Garamond(세리프 포인트) — CDN 로드.

| 항목 | 위치 | 방법 |
| --- | --- | --- |
| 원장 프로필 사진 | `assets/director.png` | 이 경로에 사진 파일을 넣으세요. (없으면 자동으로 텍스트 대체 표시) |
| 포트폴리오 사진 | `assets/work-01 ~ work-06` | 현재 SVG 자리표시자입니다. 사진(`.jpg`)으로 바꾼 뒤 `index.html`의 `src` 확장자도 함께 변경하세요. |
| 로고 | 코드 렌더링 | 로고는 세리프 텍스트로 직접 렌더링됩니다. 이미지 로고를 쓰려면 nav/footer의 텍스트를 `<img>`로 교체하세요. |
| 카카오톡 / 네이버 링크 | `script.js` 상단 `LINKS` | 실제 카카오 채널 상담 주소, 네이버 예약 주소를 입력하세요. |
| 주소 · 영업시간 | `index.html` `.contact__info` | 실제 정보로 수정하세요. |

## 특징

- 반응형 · 모바일 우선
- 스크롤 등장 애니메이션 (`prefers-reduced-motion` 대응)
