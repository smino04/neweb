# NEWEB 성수 · 남성 전문 헤어살롱 원페이지

미니멀 · 블랙 앤 화이트 · 에디토리얼 톤의 정적 원페이지 웹사이트입니다.
정적 HTML/CSS/JS로만 구성되어 있어 별도 빌드 없이 바로 배포할 수 있습니다.

## 실행

`index.html` 파일을 브라우저에서 열면 됩니다. 로컬 서버로 확인하려면:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 구성

### 메인 페이지 (`index.html`)
- **Hero** — NEWEB 성수 로고
- **Portfolio** — 포트폴리오 갤러리 (사진 계속 추가)
- **Reservation** — 네이버 예약 버튼 → **여기서 페이지 끝(로고 + 저작권 푸터)**

### 팀 페이지 (`team.html`) — 별도 페이지
- 상단 내비게이션 **"Team"** 클릭 시 이동하는 별도 페이지
- 강단 원장 소개 + 디자이너(스탭) 소개
- "← 홈으로 돌아가기" 링크로 메인 복귀

## 내 콘텐츠로 교체하기

폰트: Pretendard(한글) + Cormorant Garamond(세리프 포인트) — CDN 로드.
로고: 업로드된 로고 이미지를 벡터(`assets/logo-mark.svg`)로 변환해 사용 중 (어떤 크기에서도 선명).

| 항목 | 위치 | 방법 |
| --- | --- | --- |
| **포트폴리오 사진** | `assets/work-01.jpg` ~ `work-12.jpg` | **파일명만 맞춰서 GitHub의 assets 폴더에 업로드하면 자동으로 반영됩니다.** 사진이 없는 칸은 화면에서 자동으로 사라지므로, 지금처럼 4장만 있어도 4장만 깔끔하게 보입니다. 12장보다 더 올리고 싶으면 `index.html`의 `.gallery` 안 `<figure>` 블록을 복사해 `work-13`... 로 이어가면 됩니다. |
| 원장 프로필 사진 | `assets/director.png` | 이 경로에 사진 파일을 넣으세요. (없으면 자동으로 텍스트 대체 표시) |
